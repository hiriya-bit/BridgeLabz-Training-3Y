```html Responsive CSS Cheat Sheet
Responsive CSS Cheat Sheet

Filters

Used to change the visual appearance of images.

filter: grayscale(100%);

Media Queries

Used to apply CSS according to screen size.

@media (max-width: 700px)

Responsive Design

Design that works on different devices.

width: 100%;

Typography

Responsive text can use relative units.

font-size: clamp(...);
```
